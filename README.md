**SLY Company — Academic Project**

Projeto acadêmico de desenvolvimento web baseado na SLY Company, uma marca conceitual de streetwear. O site apresenta a identidade visual da marca, sua coleção de produtos e uma página de contato, com foco em design minimalista, organização de código e responsividade.

Desenvolvido com **HTML5, CSS3 e Bootstrap 5**, aplicando conceitos de estruturação semântica, estilização personalizada e adaptação para diferentes tamanhos de tela.

O projeto faz parte das atividades acadêmicas de desenvolvimento web e tem como objetivo aplicar, na prática, os conhecimentos adquiridos em sala de aula.
